# Task 2: Login and Registration System

## 📌 Description

A C++ program that allows users to register with a username and password, and then log in using those credentials. Credentials are stored in a text file.

## ✨ Features

- User registration with unique username
- Password confirmation during registration
- Input validation (username ≥ 3 chars, password ≥ 4 chars)
- Duplicate username check
- Secure credential storage in `users.txt`
- Login verification
- Username can contain spaces

## 🧠 Concepts Used

- File handling (`ifstream`, `ofstream`)
- String manipulation
- Functions
- Loops and conditionals
- Input validation

## 📂 Files

- `login_system.cpp` — Main source code
- `CodeAlpha_CPP_Task2_Report.pdf` — Detailed report

## ▶️ How to Run

1. Open `login_system.cpp` in Dev-C++.
2. Compile (F9) and run (F10).
3. Choose 1 to Register or 2 to Login.
