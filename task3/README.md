# Task 3: Sudoku Solver

## 📌 Description

A C++ program that solves a 9x9 Sudoku puzzle using the backtracking algorithm.

## ✨ Features

- Represents the Sudoku grid as a 2D array
- Uses backtracking to fill empty cells
- Validates row, column, and 3x3 subgrid constraints
- Displays the original puzzle and the solution
- Formatted grid output with subgrid separators

## 🧠 Concepts Used

- 2D arrays
- Recursion
- Backtracking algorithm
- Functions
- Loops and conditionals

## 📂 Files

- `sudoku_solver.cpp` — Main source code
- `CodeAlpha_CPP_Task3_Report.pdf` — Detailed report

## ▶️ How to Run

1. Open `sudoku_solver.cpp` in Dev-C++.
2. Compile (F9) and run (F10).
3. The program displays the original puzzle and the solved puzzle.
