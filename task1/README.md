# Task 1: CGPA Calculator

## 📌 Description

A C++ program that calculates the GPA for a semester and the overall CGPA based on course grades and credit hours.

## ✨ Features

- Takes input for the number of courses
- Accepts grade (A/B/C/D/F) and credit hours for each course
- Validates grade and credit hour input
- Calculates total credits and total grade points
- Computes semester GPA and overall CGPA
- Displays results in a formatted table

## 🧠 Concepts Used

- Structures (`struct`)
- Functions
- Vectors
- Loops and conditionals
- Input validation

## 📂 Files

- `cgpa_calculator.cpp` — Main source code
- `CodeAlpha_CPP_Task1_Report.pdf` — Detailed report

## ▶️ How to Run

1. Open `cgpa_calculator.cpp` in Dev-C++.
2. Compile (F9) and run (F10).
3. Enter the number of courses, grades, and credit hours.
