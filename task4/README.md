# Task 4: Banking System

## 📌 Description

A C++ program that implements a simple banking system using Object-Oriented Programming (OOP) concepts.

## ✨ Features

- Create new customers
- Create accounts for customers
- Deposit money
- Withdraw money (with balance check)
- Transfer funds between accounts
- View transaction history
- View account information
- Display all customers

## 🧠 Concepts Used

- Classes and Objects
- Encapsulation
- Composition
- Constructors and Destructors
- Vectors
- File handling (optional)

## 📂 Files

- `banking_system.cpp` — Main source code
- `CodeAlpha_CPP_Task4_Report.pdf` — Detailed report

## ▶️ How to Run

1. Open `banking_system.cpp` in Dev-C++.
2. Compile (F9) and run (F10).
3. Use the menu to perform banking operations.
